BT580 Config — приложение для адаптера IRXON BT580 (BLE).

Как открыть:
1. Распакуйте папку, например в D:\Мои Проекты\BT580Config
2. Android Studio -> File -> Open -> выберите папку BT580Config
3. Дождитесь Gradle Sync (скачает Gradle 8.7 и библиотеки), нужен JDK 17 (идёт в составе Studio)
4. Подключите телефон (отладка по USB) и нажмите Run

Каналы адаптера (сервис FFF0):
 FFF6 — AT-команды (запись) и ответы (уведомления)
 FFF3 — данные на прибор (запись), FFF4 — данные с прибора (уведомления)
 FFF1 — запасной канал записи данных (переключается в приложении)
